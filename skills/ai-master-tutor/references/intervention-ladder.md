# Intervention ladder

Use this protocol when the learner is wrong, stuck, overloaded, frustrated, or repeatedly guessing.

## Classify the error before intervening

| Error class | Observable signal | First intervention |
|---|---|---|
| Concept misconception | A stable wrong model predicts multiple answers | Contrast the two models with the smallest discriminating case |
| Missing prerequisite | No usable representation or repeated guessing | Teach the prerequisite briefly, then request a tiny use |
| Broken reasoning chain | Premises may be sound, but a link is absent or invalid | Mark the exact link and offer a causal/logical connector |
| Procedure or sequence error | Right goal, wrong/missing order or decision point | Externalize steps and use a completion problem |
| Ignored condition | Rule is applied outside its stated constraints | Highlight the condition and change only that variable |
| Unclear expression | Example or follow-up suggests understanding despite vague wording | Ask for an example, contrast, diagram, or restatement before judging |
| Careless/calculation slip | Method is sound; execution differs at one location | Point to the exact slip and retry without reteaching the concept |
| Overgeneralization | A valid local rule is claimed universally | Give a boundary case and ask the learner to narrow the rule |
| Transfer failure | Original form succeeds; changed surface form fails | Ask which deep feature is shared, then bridge near → varied transfer |

Do not infer a stable trait from one mistake.

## Use the correction protocol

1. **Preserve** — State the part that is correct or productive.
2. **Locate** — Name the error class and exact step, condition, or assumption.
3. **Hint** — Give the smallest cue likely to unlock a correction.
4. **Retry** — Ask the learner to revise the original answer.
5. **Scaffold** — After failure, add a choice, partial structure, or parallel worked example.
6. **Explain** — Give the complete model only after graded support fails or the learner requests it.
7. **Regenerate** — Use a changed or parallel item so the learner produces the model again.

Default feedback shape:

```text
你做对了什么：...
问题具体在哪里：...
一个最小提示：...
请重新尝试：...
```

Adapt the language naturally. Do not display all labels when one sentence is clearer.

## Escalate help deliberately

Use one rung at a time unless evidence calls for more:

0. **Independent** — no hint.
1. **Orient** — point attention to the relevant feature.
2. **Cue** — name the principle or representation.
3. **Constrain** — offer a choice, subgoal, partial equation, or sentence stem.
4. **Model** — demonstrate a parallel example and ask for self-explanation.
5. **Explain** — give the direct answer and causal reason.
6. **Re-attempt** — use a new item; never count copying as mastery.

After two unsuccessful attempts at one rung, escalate. After a supported success, reduce one rung on the next item. If two errors show a prerequisite gap, drop the ICAP mode as well as increasing support.

## Repair a misconception

1. Elicit or use the learner's stated prediction.
2. Find the smallest case where the learner's model and target model diverge.
3. Ask the learner to compare the predictions.
4. Explain the decisive feature only if needed.
5. Ask the learner to rewrite the original model.
6. Test one ordinary case and one boundary case.

Avoid “not quite” without a diagnosis. Name the model that generated the error.

## Respond to “I don't know”

- First occurrence: offer a small choice, familiar example, or sentence starter.
- Second occurrence on the same idea: teach the missing piece directly.
- After explanation: request a tiny action such as choosing, labeling, or completing one step.
- Continued difficulty: reduce the target, change representation, or pause.

## Respond to overload or fatigue

1. Stop introducing new content.
2. State what is already secure in one sentence.
3. Select one obstacle and at most one relationship.
4. Offer a choice, completion item, half-built structure, or worked example.
5. Ask one question only.
6. Return from P/A toward C/I only after the learner stabilizes.

Do not add a motivational speech when the learner needs cognitive relief.

## Prevent question prison

Stop Socratic questioning and explain when:

- the learner lacks facts required to infer the answer;
- attempts have become guesses rather than reasoning;
- the learner explicitly asks for an explanation;
- two attempts at the current support level fail;
- frustration or overload is rising;
- correctness is safety-critical;
- the available time favors a worked example.
